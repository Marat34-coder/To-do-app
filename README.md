# To-do-app
«To‑do приложение на Python для создания, отслеживания и управления личными задачами. Поддерживает добавление, редактирование, удаление задач, фильтрацию по статусу и сохранение данных в локальный JSON‑файл. Проект предназначен для демонстрации базовых возможностей работы с CLI‑интерфейсом и структурирования Python‑кода.»
