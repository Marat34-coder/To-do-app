# 📝 To-Do List (Console App)

Простой консольный список задач на Python. Приложение позволяет добавлять, просматривать и удалять задачи прямо в терминале.

## 🚀 Возможности

- ✅ Добавление новых задач.
- 📋 Просмотр всех текущих задач.
- ❌ Удаление задач по номеру.
- 🔄 Работа в цикле до выбора пункта «Выход».

## 🛠 Требования

- Python 3.x (проверь версию командой `python --version` или `py --version`).

## ▶️ Как запустить

1. Открой терминал в папке с проектом.
2. Запусти скрипт командой:

   ```bash
   python "To-do list.py"
